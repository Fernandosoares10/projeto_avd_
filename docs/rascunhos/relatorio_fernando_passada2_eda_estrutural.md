No nosso projeto, trabalhamos com alguns conceitos importantes. O primeiro é MCAR, MAR e MNAR, que são tipos de mecanismos de ausência dos dados. O MCAR acontece quando os valores estão ausentes completamente ao acaso, sem depender de outras informações. O MAR acontece quando a ausência está relacionada com outras variáveis que conseguimos observar, como gênero ou categoria do cartão. Já o MNAR acontece quando a ausência depende do próprio valor que está faltando, como uma pessoa que prefere não informar sua renda por causa do valor que recebe.

Para analisar isso, utilizamos as tabelas do notebook eda_unknown.ipynb, principalmente as que mostram as taxas de Unknown por Attrition_Flag, Gender e Card_Category, além das comparações das medianas das variáveis numéricas entre os registros conhecidos e desconhecidos. Essas tabelas ajudam a identificar se existe alguma relação entre os valores ausentes e outras informações, mas não conseguimos afirmar com total certeza qual é o mecanismo, apenas identificar o mais provável.

Outro ponto importante é a padronização no K-Means. Esse algoritmo utiliza a distância euclidiana para calcular a proximidade entre os dados e formar os grupos. Como nossas variáveis possuem escalas diferentes, como altura, peso e idade, sem a padronização algumas variáveis poderiam ter muito mais influência no cálculo das distâncias do que outras. Por isso utilizamos o StandardScaler, que deixa as variáveis com média próxima de zero e desvio padrão igual a um, fazendo com que todas tenham uma participação mais equilibrada na formação dos grupos.

Sobre as métricas, como o K-Means é um algoritmo não supervisionado, ele não utiliza as classes reais para formar os grupos, apenas identifica semelhanças entre os registros. Depois que os clusters foram criados, fizemos um mapeamento, relacionando cada grupo com a classe real que aparecia com maior frequência nele. A partir disso conseguimos calcular as métricas. A acurácia mostra a porcentagem total de registros classificados corretamente, que no nosso projeto foi de aproximadamente 38,8%. A precisão mostra, entre os registros que receberam determinada classe, quantos realmente pertenciam a ela. Já o recall mostra quantos registros de uma determinada classe real foram identificados corretamente. Esses resultados mostram que o K-Means conseguiu formar grupos, mas não conseguiu representar muito bem todas as classes originais.

Por último, utilizamos o PCA, que é uma técnica de redução de dimensionalidade. Como o K-Means trabalhou com oito variáveis numéricas, seria difícil representar todas elas em um gráfico comum. Então o PCA transforma essas variáveis em novas componentes, permitindo visualizar os dados em apenas duas dimensões. No nosso caso, as duas componentes principais representam aproximadamente 41,3% da variância total, ou seja, conseguem mostrar uma parte das informações presentes nos dados originais, mas não tudo. É importante lembrar que o PCA foi utilizado apenas para facilitar a visualização dos grupos, enquanto o K-Means continuou trabalhando com as oito variáveis padronizadas.
